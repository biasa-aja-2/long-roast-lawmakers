One satirical sentence, at most 320 characters, roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF. The setup grants them authority — a 900-page law to govern artificial intelligence — and the turn undercuts it with the file they cannot convert: they print the bill, scan it back in sideways, and ask an intern which button turns it into a PDF.

> They can draft a 900-page law to govern artificial intelligence, but the same lawmakers still print the bill, scan it back in sideways, and ask an intern which button turns it into a PDF.

## Run it

```sh
python3 main.py
```

The program self-checks the kit's gates (UTF-8, 1–320 characters, one line, not whitespace-only, no control characters) and refuses to write if any gate fails, then writes the sentence to `/output/entry.txt` and verifies it by reading it back.
